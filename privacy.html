声之廊 · 隐私政策

生效日期：2026 年 10 月 2 日　|　版本：V1.0

《声之廊》（下称"本应用"）是一款由个人开发者独立开发的单机音乐创作游戏。我们高度重视您的个人信息与隐私。本政策说明本应用在不同发行版本中对信息的处理方式。请您在使用前仔细阅读。

一、总则：本应用以"本地运行"为默认形态

本应用的核心设计是完全在您的设备本地运行：您创作的全部作品（涂鸦、演奏录音、成绩）、设置、成就与图鉴数据仅保存在设备本地存储中，不上传任何服务器，不建立账号体系，不包含任何内购。

二、按发行渠道划分的信息处理

2.1 TapTap 渠道版本（安卓）

com.zjw11398925.emotionplayground为符合国家关于网络游戏防沉迷与实名认证的规定，本渠道版本接入了 TapTap 官方防沉迷 SDK（tap-core / tap-login / tap-compliance）。仅在首次启动时：

  • 通过 TapTap SDK 建立网络连接，完成 TapTap 登录与实名认证；此过程中 SDK 会处理设备标识信息与应用包名、应用签名，用于合规校验；
  • 实名认证所涉及的姓名与身份证号码等实名信息由 TapTap 平台依据其自身的隐私政策处理，本应用不接收、不存储、不传输此类信息；
  • 认证通过后，防沉迷系统依据国家规定对未成年人实施游玩时段与时长管理。

完成首次实名认证后，本应用即可完全离线游玩，后续运行不再发起网络请求（防沉迷会话由 SDK 本地维持）。

2.2 其他全部渠道（Web / GitHub / Google Play / Windows / iOS）

上述渠道的版本不包含任何联网代码与第三方数据收集组件：自启动至退出零网络请求、零设备信息采集、零用户行为统计、零崩溃上报。

三、本地数据的控制

  • 存储范围：仅作品数据、应用设置、图鉴与成就进度，全部位于设备本地；
  • 导出行为：导出 GIF / MP3 文件在设备本地完成编码生成；导出与分享完全经由您设备的系统分享面板自主完成，本应用不经手任何网络传输；
  • 删除方式：您可随时在应用内清除数据，或卸载应用以彻底删除全部本地数据。

四、第三方组件声明

  • TapTap 防沉迷 SDK（仅 TapTap 渠道版本包含）：提供登录、实名认证与防沉迷能力，其数据处理遵循 TapTap 隐私政策；
  • lamejs（MP3 本地编码，LGPL-3.0 许可）：纯本地运行，无任何数据收集行为；
  • 乐器采样音源（CC-BY / CC0 / 公有领域）：静态音频资源，无任何数据收集行为。

五、未成年人保护

TapTap 渠道版本依据国家新闻出版署相关规定接入防沉迷实名系统：未成年人仅可在规定时段游玩，游玩时长受限制。实名信息由 TapTap 平台处理，本应用不存储。其他渠道版本为纯单机软件，不涉及网络游戏服务。

六、政策变更

如本政策发生变更，我们将在本页面更新并修订生效日期。重大变更将通过应用内提示告知。

七、联系我们

如您对本政策有任何疑问，可通过 TapTap 社区（应用详情页）与我们联系。
